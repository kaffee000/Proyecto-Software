Antes de empezar
-tener instalado JAVA
-usuarios dentro de CSV deben de estar en la base de datos 
-proyecto debe de estar en ejecución 
-para pruebas relacionadas a inscripciones es necesario cambiar la ruta de donde este ubicado el CSV
	-CSV Data Set Config
	-Filename (aquí se debe de cambiar la ruta si corresponde)

Pasos
1. Abrir JMeter
2. Abrir carpeta con archivos JMX
3. Presionar botón de start

Los resultados o respuestas se encuentran en "View Results Tree"
